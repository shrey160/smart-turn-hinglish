# Hinglish Turn Detection — Demo App

Gradio demo for the **Hinglish turn detection model (v2, `s2-004`)**: record or
upload audio and get a verdict — is the user **done speaking** (agent can
respond) or **just pausing** (keep listening) — with p(complete), inference
latency, and a TEN VAD trailing-silence readout.

- Weights / model card: https://huggingface.co/Shrey160/hinglish-turn-v2
- Full project: https://github.com/shrey160/smart-turn-hinglish (`REPORT.md` has the complete story)

## Run

**Inside the repo (uv):**

```powershell
uv run python app/app.py --selftest     # headless check on test-B clips (prints PASS)
uv run python app/app.py                # UI at http://127.0.0.1:7860
```

**Standalone (any machine with Python 3.10+):**

```powershell
pip install -r requirements.txt
python app.py                           # downloads model files from HF Hub on first run
```

No local model files are required: the app looks for the ONNX in the repo
first, then auto-downloads `onnx/s2-004.fp32.onnx` / `onnx/s2-004.int8.entropy-quint8.onnx`
from the HF Hub (cached after the first run).

## UI controls

| Control | Default | What it does |
|---|---|---|
| Audio input | — | record from mic or upload a file (any sample rate; resampled to 16 kHz mono) |
| Model | fp32 ONNX (bit-faithful) | switch to int8 (9 MB, −2.5 test-A acc, ~13 ms p50) |
| Decision threshold τ | 0.5 | higher = fewer false interrupts, longer holds (P6 policy sweep: test-B is flat τ 0.25–0.85) |
| Trailing context | 8 s | simulated streaming — show the model only the LAST b seconds (0.5–8 s) and watch the verdict flip; mirrors the P6 latency curve (accuracy saturates ~2–4 s) |

Outputs: verdict, p(complete), ONNX forward time (ms), trailing silence
(TEN VAD speech-gate, with an energy-floor fallback if `ten_vad` is
unavailable on the host).

## How it works

```
audio → 16 kHz mono float32 → keep LAST b s → zero-pad FRONT to 8 s (shared
contract) → whisper-tiny log-mel (80 × 800, unnormalized — v2 convention, see
REPORT.md §7) → ONNX (logits) → sigmoid → p(complete) → τ decision
```

The input contract is identical to Smart Turn; the model is a whisper-tiny
encoder + attention-mean head trained with the two-stage recipe (pretrain on
Smart Turn hin+eng → finetune on TTS Hinglish + replay). Details and
limitations: [`../REPORT.md`](../REPORT.md).

## HF Space hosting

Gradio Spaces are currently **PRO-gated** on HF (free accounts get static
Spaces only — see the project's HARDPOINT note). To host this app:

- with PRO: `uv run python scripts/upload_hf.py --space` creates
  `Shrey160/hinglish-turn-demo` from this folder automatically, or
- manually: create a Gradio Space and upload `app.py` + `requirements.txt`
  (the README header it needs is generated by the script), or
- self-host anywhere: `pip install -r requirements.txt && python app.py`.
